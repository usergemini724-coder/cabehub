# CabeHub · Steal An Egg (Roblox)

Hub all-in-one **tanpa signin/key** untuk Roblox *Steal An Egg* (placeId `107778070777162`).

## Loader (1 baris)

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/usergemini724-coder/cabehub/main/CabeHub.lua"))()
```

Executor: Solara / Delta / Xeno / Wave / Real.

## Fitur

| Tab | Fitur |
|---|---|
| **EGG** | Scanner egg map-wide, rarity engine resmi (10 tier), ESP highlight + label (nama/rarity/jarak/owner), filter rarity/jarak/pencarian, TP per-egg / Terdekat / Terbaik, Auto-Steal radius |
| **PLAYER** | WalkSpeed (16–150), JumpPower (50–300), Noclip, Infinite Jump |
| **MISC** | Anti-AFK, Rejoin Server, FPS Boost, Reset Filter |

Toggle UI: **RightControl** · Config auto-save (`CabeHub_config.json`) · Re-execute script = unload.
